# Documentation index

This folder contains the main project documentation.

- `architecture.md` – explains the system structure and data flow
- `calibration.md` – explains the calibration workflow and EEPROM logic
- `setup.md` – explains installation and startup

Start with `setup.md` if you want to run the project, and with `architecture.md` if you want to understand how the parts fit together.
